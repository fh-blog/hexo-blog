## 前言

开发中最烦什么？`npm install` 转圈五分钟、`git clone` 速度 20KB/s、GitHub 页面打不开。这些问题根源是网络链路不通，不是代码写错了。这篇整理了 2026 年实用的代理工具选型、订阅节点配置、以及 npm/Git/终端/浏览器的全套网络加速方案。

## 二、订阅与节点配置

### 订阅是什么

"订阅"是一个 URL，指向服务商提供的节点列表。客户端导入订阅后，会自动解析出所有可用节点并定期更新。

```
# 典型订阅地址格式
https://your-provider.com/sub?token=xxxxxx

# 也可以是 Base64 编码的节点链接
vmess://eyJ2Ijoi...
vless://uuid@ip:port?encryption=...
trojan://password@ip:port?...
ss://base64encoded@ip:port
```

### Clash Verge Rev 配置步骤

1. **下载安装**：[GitHub Release](https://github.com/clash-verge-rev/clash-verge-rev/releases) 下载对应系统版本
2. **导入订阅**：`配置` → `新建` → 粘贴订阅链接 → `确定`
3. **更新订阅**：右键托盘图标 → `更新订阅`（建议在 `设置` 中开启自动更新）
4. **选择节点**：`代理` 页面 → 点击节点延迟测试 → 选择延迟最低的
5. **切换模式**：`规则`（按规则分流）/ `全局`（全部走代理）/ `直连`（全部不走）

### 分流规则要点

```
# Clash 规则示例（决定哪些流量走代理）
rules:
  # 开发相关 —— 走代理
  - DOMAIN-SUFFIX,github.com,Proxy
  - DOMAIN-SUFFIX,raw.githubusercontent.com,Proxy
  - DOMAIN-SUFFIX,stackoverflow.com,Proxy
  - DOMAIN-SUFFIX,npmjs.com,Proxy
  - DOMAIN-SUFFIX,docker.com,Proxy
  - DOMAIN-SUFFIX,pypi.org,Proxy
  
  # 国内网站 —— 直连
  - DOMAIN-SUFFIX,cn,DIRECT
  - DOMAIN-SUFFIX,baidu.com,DIRECT
  - DOMAIN-SUFFIX,npmmirror.com,DIRECT
  
  # 局域网 —— 直连
  - IP-CIDR,192.168.0.0/16,DIRECT
  - IP-CIDR,10.0.0.0/8,DIRECT
  
  # 兜底
  - MATCH,Proxy
```

### sing-box 配置思路

sing-box 的配置方式和 Clash 不同，以 JSON 为主，但逻辑相似：

```json
{
  "inbounds": [{
    "type": "tun",
    "tag": "tun-in",
    "address": ["172.19.0.1/30"],
    "auto_route": true,       // 自动接管系统流量
    "strict_route": true
  }],
  "outbounds": [
    { "type": "selector", "tag": "proxy", "outbounds": ["auto"] },
    { "type": "urltest", "tag": "auto", "outbounds": ["🇭🇰01", "🇸🇬02", "🇯🇵03"] },
    { "type": "direct", "tag": "direct" }
  ],
  "route": {
    "rules": [
      { "domain_suffix": ["github.com", "npmjs.com"], "outbound": "proxy" },
      { "domain_suffix": ["cn", "baidu.com"], "outbound": "direct" },
      { "geoip": "cn", "outbound": "direct" }
    ]
  }
}
```

> sing-box 推荐用 `tun` 模式（虚拟网卡）代替传统 HTTP/SOCKS 代理，对终端程序更友好，不需要额外配置 `http_proxy` 环境变量。

## 三、npm / Git 镜像加速

### npm

```bash
# 推荐：淘宝镜像（10 分钟同步一次）
npm config set registry https://registry.npmmirror.com

# 腾讯云镜像（南方用户更快）
npm config set registry https://mirrors.cloud.tencent.com/npm/

# 查看当前源
npm config get registry
```

### Git

```bash
# 走代理（假设本地代理端口 7890）
git config --global http.proxy http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890

# 只代理 GitHub（不影响公司内网仓库）
git config --global http.https://github.com.proxy http://127.0.0.1:7890

# 取消代理
git config --global --unset http.proxy
git config --global --unset https.proxy
```

**GitHub 克隆加速**：

```bash
# 走 ghproxy 镜像
git clone https://ghproxy.com/https://github.com/user/repo.git

# SSH 走代理（~/.ssh/config）
Host github.com
    HostName github.com
    User git
    Port 22
    ProxyCommand nc -X 5 -x 127.0.0.1:7891 %h %p
```

## 四、系统与终端代理

### Windows

```
设置 → 网络和 Internet → 代理 → 手动设置代理
地址：127.0.0.1    端口：7890
```

```powershell
# 命令行开启
netsh winhttp set proxy 127.0.0.1:7890

# 关闭
netsh winhttp reset proxy
```

### macOS / Linux 终端

```bash
# 写入 ~/.zshrc 或 ~/.bashrc，用别名开关
alias proxy='export http_proxy=http://127.0.0.1:7890; export https_proxy=$http_proxy; export all_proxy=socks5://127.0.0.1:7891'
alias unproxy='unset http_proxy https_proxy all_proxy'

# 使用：终端执行 proxy 开启，unproxy 关闭
```

> **提示**：使用 Clash Verge Rev 的 TUN 模式或 sing-box 的 tun 入站，可以省去终端手动 `export` 这一步，系统级接管流量。

## 六、常见问题排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 客户端显示已连接但网页打不开 | 系统代理没生效 | 检查系统代理设置是否指向 127.0.0.1:7890 |
| 终端不走代理 | 终端不读取系统代理 | 手动 `export http_proxy`，或用 TUN 模式 |
| 部分网站正常、部分打不开 | 分流规则问题 | 检查规则，把目标域名加入 Proxy 规则 |
| 订阅更新失败 | 订阅链接过期或网络不通 | 先开全局模式再更新，或联系服务商刷新订阅 |
| 节点全超时 | 端口被占用或防火墙拦截 | 检查端口 7890/7891，换一个端口试试 |
| `git clone` 超时 | Git 没走代理 | `git config --global http.proxy` 配置 |
| 内网地址也走了代理 | 规则没排除局域网 | 规则中加 `IP-CIDR,192.168.0.0/16,DIRECT` |

## 七、稳定可靠建议

1. **客户端选活跃维护的**：Clash Verge Rev / sing-box 更新频繁，遇 BUG 能及时修复
2. **订阅定期更新**：服务商节点会变动，建议开启客户端自动更新订阅
3. **多备几个协议节点**：VLESS + Hysteria2 双协议，封端口不封协议的情况常见
4. **不要混用代理和 VPN**：同时开会互相冲突，用哪个关另一个
5. **TUN 模式更省心**：避免每个终端工具单独配代理环境变量
6. **规则写对减少误伤**：直连规则漏了内网 IP 段，会让局域网服务连不上

## 九、国内使用注意事项

代理工具在国内涉及敏感领域，使用前务必了解以下底线：

### 法律红线

1. **《网络安全法》** 规定：未经批准，不得自行建立或使用 VPN 进行跨境联网活动。个人自用的灰色地带较模糊，但**严禁用于营利、传播违法信息等行为**。
2. **用途约束**：仅限技术学习、资料查阅、开源贡献等正当用途，**禁止用于翻墙访问违法内容、传播敏感信息、攻击网络等非法活动**。
3. **备案要求**：企业/机构搭建跨境专线需向工信部备案，个人无合规渠道。

### 那到底能不能用？

```
✅ 可以做的事：
   - npm install、git clone GitHub 开源项目加速
   - 查阅 StackOverflow / GitHub Issues 技术资料
   - 访问技术文档站（MDN、Rust docs 等）

❌ 绝对不能做的事：
   - 发布违法或敏感内容
   - 攻击、渗透、扫描国内网站
   - 商用转售或为他人提供翻墙服务
   - 用代理绕过公司安全管控
```

> **一句话**：开发提速、技术学习属于灰色地带且普遍存在，低调使用、不牟利、不传播、不越线。

## 十一、免费 VPN 应用

不想折腾 Clash/V2Ray 配置？下面这些是开箱即用的免费 VPN 应用，适合临时或轻度使用。

### 主流免费 VPN 对比

| 名称 | 免费流量 | 国内可用性 | 平台 | 特点 |
|------|---------|-----------|------|------|
| **ProtonVPN** | 无限流量 | ⭐⭐⭐ 中等 | Win/Mac/Android/iOS/Linux | 瑞士公司，无日志政策，开源审计，免费版连 3 国 |
| **Windscribe** | 10GB/月 | ⭐⭐ 较低 | Win/Mac/Android/iOS/浏览器 | Stealth 协议有时可用，免费服务器少 |
| **Psiphon** | 无限 | ⭐⭐⭐ 中等 | Win/Android/iOS | 加拿大非营利组织，混合协议，非高峰期 50-60% 连通 |
| **Lantern（蓝灯）** | 500MB/月(免费) | ⭐⭐ 较低 | Win/Mac/Android/iOS | P2P 代理，依赖志愿者节点，速度不稳定 |
| **Tor Browser** | 无限 | ⭐⭐⭐ 较高 | Win/Mac/Linux/Android | 隐私最强，配合 obfs4 网桥可用性 ~70%，但速度慢（2-5Mbps） |
| **Mullvad Browser** | 不提供 VPN | — | Win/Mac/Linux | 隐私浏览器，需配合自建 VPN 使用 |
| **TonboVPN** | 200MB/天 | ⭐⭐ 较低 | Win/Mac/Android/iOS | 每日免费额度，适合偶尔查资料 |

### 免费 VPN 的局限

```
免费 VPN 在国内的硬伤：
├── IP 池被大量标记 → GFW 快速识别封锁
├── 敏感时期几乎全挂 → 可靠性 0
├── 隐私堪忧 → 部分免费 VPN 卖数据给广告商
├── 速度感人 → 看 YouTube 1080p 都够呛
└── 线路少 → 仅 3-5 个地区，很多站打不开
```

### 各场景推荐

| 场景 | 推荐 | 理由 |
|------|------|------|
| 临时查资料 | Psiphon 或 ProtonVPN | 无需注册/有免费无限流量 |
| 注重隐私 | Tor Browser + obfs4 网桥 | 匿名性最强，无中心化服务器 |
| 文档查阅 + 轻量浏览 | ProtonVPN 免费版 | 开源审计、无限流量 |
| 看视频/大流量 | **不推荐免费** → 选付费机场 | 免费带宽根本扛不住 |
| 稳定日常使用 | 付费机场 ¥7-38/月 | 年付均摊每天不到 1 块钱 |

> **一句话总结**：免费 VPN 适合应急查个资料，ProtonVPN（无限流量）和 Tor Browser（隐私最强）是其中少数靠谱的。但真需要稳定、高速、全解锁，还是得付费机场。

## 总结

```
选客户端    → Clash Verge Rev（桌面）/ sing-box（全平台）
获取节点    → 付费机场最稳（¥7-38/月），免费节点临时应急（注意安全风险）

分流规则    → GitHub/npm 走代理，国内/内网直连
系统代理    → 改系统代理地址指向 127.0.0.1:7890，或用 TUN 模式一把梭
git clone慢 → 配 http.proxy 或用 ghproxy 镜像
npm install慢 → 换 npmmirror 镜像源
免费 VPN    → ProtonVPN（无限流量）/ Tor Browser（隐私最强）应急用
国内注意    → 仅限技术学习，不商用不传播，金融操作走直连
```
